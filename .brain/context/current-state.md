- Navbar refresh stability now depends on the theme bootstrap in `src/app.html` publishing the resolved theme before hydration and `src/routes/+layout.svelte` hiding the header toggle until client theme state is synchronized.
- `src/lib/components/NavAvatar.svelte` is a navbar-only avatar that keeps a stable circle during image loading and only falls back to `J` on a true missing or error state.
- Blog comments for `src/routes/blog/[slug]/+page.svelte` now load from the page component instead of `+page.ts` because PocketBase uses `window.fetch`; keeping that call out of `load` avoids SvelteKit's route-fetch warning.
- When loading route-specific client data from `src/routes/blog/[slug]/+page.svelte`, guard `$page.params.slug` before using it in effects. The first pass failed `pnpm check` because the slug is typed as `string | undefined` until narrowed.
- GitHub PR preview links are generated by `.github/workflows/coolify-preview-link.yml`, which comments the expected Coolify preview URL onto each pull request once the workflow exists on `trunk`.
- The repository webhook that points at Coolify's manual GitHub webhook must subscribe to both `push` and `pull_request` events or Coolify will never see PR previews.
- The Coolify app must have Preview Deployments enabled in the dashboard. Without that app-side toggle, Coolify accepts the PR webhook and responds with `Preview deployments disabled.`, and the preview URL stays unavailable.
