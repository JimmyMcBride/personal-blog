- GitHub PR preview links are generated by `.github/workflows/coolify-preview-link.yml`, which comments the expected Coolify preview URL onto each pull request once the workflow exists on `trunk`.
- The repository webhook that points at Coolify's manual GitHub webhook must subscribe to both `push` and `pull_request` events or Coolify will never see PR previews.
- The Coolify app must have Preview Deployments enabled in the dashboard. Without that app-side toggle, Coolify accepts the PR webhook and responds with `Preview deployments disabled.`, and the preview URL stays unavailable.
